# Windows / macOS 平台规则

先通过环境信息识别系统，只读取对应平台的实现细节。支持 Windows 和 macOS；WSL/Linux 或无法确认的环境只提供方案，不能套用某平台删除动作。无需管理员权限完成一般文件分析；遇权限阻止就报告未统计范围，不通过修改系统设置绕过。

## 两个平台共同要求

- 为用户批准的课根建立真实边界，区分入口、目标和实际卷。默认不跟随符号链接/重解析点；用户明确指定链接入口时先解析到实际根，再限制扫描在该根。子项链接、挂载和云占位单列，不穿越递归。通过文件身份识别多个入口和硬链接，不能按路径重复承诺收益。
- 不自动安装 Python、包管理器或系统工具。已有运行时可使用文件 API；没有时使用系统已有工具，无法可靠检查的部分写为未知。路径含中文、空格、引号、通配符或 shell 字符时传字面参数，不拼接成可执行命令。
- 云端文件先查本地状态。待上传、同步失败、仅云端、状态不明的项只报告，不为哈希自动下载。不改云同步设置；同步文件夹中的“删除文件”可能传播到云端和其他设备，若目标只是腾本地空间，应优先提出提供方的释放本地副本功能，并明确影响、获批后才执行。
- 记录逻辑字节及可可靠获取的本地占用；未知就标未知。主内容哈希不涵盖所有元数据、NTFS 附加流、资源分支等，不据此把附加数据不同的对象当成完全重复。
- 回收站/废纸篓是暂存，不默认视为已释放。不得删除其他已有回收项、批量清空整卷或整个回收站，也不自动移除系统快照来兑现预计收益。

## Windows

- 用原生 PowerShell / 文件 API 读取元数据和处理文件；文件操作全程保持同一 shell。使用 `-LiteralPath` 或等价字面 API，不把 PowerShell 枚举结果交给 `cmd /c`、批处理内建或拼接命令删除。
- 核对文件身份字段确实有效；若枚举接口返回的卷/文件身份或链接数为零、缺失或异常，改用逐文件元数据接口核实（已有 Python 时可检查 `os.stat`）。不能把零值/缺失身份当成所有文件共享的去重键；仍无法核实时标注去重与收益未核实。
- 识别 junction、符号链接、其他 reparse point、占位属性和实际卷；D 入口指向 E 时，收益归 E。长路径读取失败应选支持长路径的现有文件 API，并保留原路径映射；不修改系统长路径策略，也不跳过错误后声称全量通过。
- 执行任何递归删除或移动前，必须验证解析后的绝对目标仍在用户批准课根内。优先按批准的逐文件清单操作；只有明确获批且核实为空的目录才移除。
- 硬链接多个名字共享同一文件：删除部分名字不等于释放完整文件内容。对去重或备份完整性，分别处理主流、ADS 等附加信息；无法验证就限定声明范围。
- `Remove-Item` 不等于移入回收站。需要回收站暂存时使用明确支持该语义的可用接口；接口不确定时先报告，不以永久删除替代。文件占用或状态变化则跳过，不关闭用户应用。

## macOS

- 不假定存在 C/D 盘符。`/Volumes` 下的对象可能是本地、外置或网络挂载；记录实际挂载点与卷身份，不能只凭名称判断物理盘。删除前重新核实挂载仍相同，避免外置盘拔出、重挂载或同名盘导致错目标。
- 使用 macOS 自带文件工具或已有运行时；不要照搬 GNU 专用的 `stat`/`du` 参数，也不假定存在 Python 3。工具读取失败时保留未知，不安装依赖或修改权限。
- Finder 显示为单个文稿的 package/bundle 实际可能是目录。默认按整体对象处理 `.app`、文稿包和资源库，包内只读检查需单独说明；不能因为内部目录名为 cache/preview 而局部删除。不要仅依赖扩展名判断是否为目录包。
- 不自动读取 iCloud 占位的完整内容；检查 Finder/提供方可得的下载和同步状态。状态未知即保留。不要通过操作 `.icloud` 标记文件来“清缓存”。
- APFS 克隆可能共享数据块，硬链接、稀疏文件、快照和共享容器会使逻辑字节与实际回收量不同；不能将同容器各卷可用空间相加。占用数据不可靠时报告候选逻辑减少和未知的实际回收量，完成后复测同一指标。
- `rm` 是永久删除，不是废纸篓操作。需要废纸篓语义时优先用 Finder 或已验证支持该语义的可用接口；不得用未经验证的通配符移动到 `~/.Trash`，外置卷废纸篓也不能当作普通缓存清空。永久删除仅处理获批的精确对象，路径复核与变更检查同样适用。
- 资源分支、扩展属性和包结构可能影响文稿完整性；验证备份或重复副本时不要仅依据数据分支哈希。没有 macOS 应用可运行时，不宣称 Keynote/PowerPoint/视频项目已完成编辑或播放测试。
