# 课件空间清理 Skill

帮助 Codex 整理 Windows 或 macOS 上的课件项目，先选择检查范围，再只读扫描文件和依赖，计算 A/B/C 三种方案各自的候选清理量，最后选择保留程度。适合课件历史版本、预览图和制作素材长期积累的情况。

| 方案（清理内容） | 保留目标 |
|---|---|
| A 保守（清早期预览图等可再生产物） | 保留版本、源素材、脚本和关键验收 |
| B 售后修改（清旧工作 PPT、过程预览、指定回退版本、已确认营销资料） | 保留当前定稿及售后修改所需资料 |
| C 交付优先（清 B 档候选项及非必要制作源文件、重建过程） | 保留当前交付和必要依赖，接受以后大改需要重做 |

**容量和百分比由你选中的实际文件逐项核算，不套用历史样本。** 扫描后会展示每档预计清理容量、比例、保留容量和主要影响；尚不能确认用途或依赖的文件不计入默认清理量。扫描不完整时会注明统计范围与缺口。数字表示候选文件大小，实际释放的磁盘空间仍需清理后测量。

## 安装

支持 Agent Skills 的客户端可使用（需要 Node.js 和 npx）：

```bash
npx -y skills add pan-11/courseware-storage-cleanup -g --all
```

也可以下载仓库，将 `skills/courseware-storage-cleanup` 文件夹复制到 Codex 的 skills 目录：

- Windows：`%USERPROFILE%\.codex\skills\courseware-storage-cleanup`
- macOS：`~/.codex/skills/courseware-storage-cleanup`

如果配置了其他 Codex skills 目录，请放到对应目录。`SKILL.md`、`agents` 和 `references` 要一起保留。

## 使用

在 Codex 中输入：

> 使用 $courseware-storage-cleanup，先检查我选中的课件文件夹，算出 A/B/C 三种方式分别预计清理多少空间，再让我选择。暂时不要删除。

Skill 先确定一个或多个检查目录；路径明确即可开始只读扫描。它会按同一份文件清单核算三档，展示真实候选容量，并在每个选项的括号中说明清理内容，再让你选择。已指定档位时沿用选择，仍提供三档比较；只要报告时不会要求立即选择。**选择档位不代表批准删除，实际删除须确认具体清单和处置方式。**

完成后，如果空间仍不足，Skill 会说明如何核对和删除不再需要的 Codex 聊天。课件清理不会自动删除聊天；归档或压缩上下文不保证释放聊天记录的磁盘空间。

## 适用范围与验证

- 不包含清理脚本或自动定期删除任务；Skill 使用客户端已有的文件工具。
- 会区分实际存储卷、云文件状态、备份占用，以及文件大小与实测释放量。
- Windows 侧已完成结构及流程验证；macOS 侧已做规则审阅和情景模拟，**尚未在 Mac 上实机验证**。
- 本仓库包含运行 Skill 所需文件，不包含课件正文、聊天记录、私人路径或本地工作日志。
